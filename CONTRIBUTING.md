# Contributing to File Organizer

Thank you for your interest in contributing! This project is open source and community-driven.

## How to Contribute

### Reporting Bugs
- Use GitHub Issues
- Describe the bug clearly
- Include steps to reproduce
- Mention your device and Android version

### Suggesting Features
- Open a GitHub Issue with the "enhancement" label
- Describe the feature and its use case
- Reference the original concept if applicable

### Pull Requests
1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Submit PR with clear description

## Code Style
- Follow Dart/Flutter style guide
- Use meaningful variable names
- Add comments for complex logic
- Keep widgets small and focused

## Commit Messages
- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Reference issues when applicable
